# The Turning Table — Cake Studio demo

A separate frontend demo for The Turning Table, built with React, Vite, Tailwind CSS and Lucide React. No existing website is modified.

## Run locally

Requires Node.js 20.19+ or 22.12+.

1. Open a terminal in this directory.
2. Run `npm install`.
3. Run `npm run dev` and open the local URL shown.
4. Run `npm run build` to create the production files in `dist/`.

The cake and contact forms open a prefilled WhatsApp message; no data is stored or sent by this website. Gallery photography is representative demo imagery hosted by Unsplash, not verified bakery work. Google Fonts, images and the map require an internet connection. Instagram is a placeholder. Replace demo imagery and verify the address/map and social link before deploying.
